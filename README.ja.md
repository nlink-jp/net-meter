# net-meter

1 つのネットワークインターフェースの現在の上り/下り速度を、数値とグラフで macOS の
メニューバーに表示します。

同じことができる既存のアプリは、統合システムモニタの一機能として提供されています。
net-meter はこれだけを行います。

[English](README.md)

## 動作環境

- macOS 26 以降、Apple Silicon。
- 権限は不要です。プライバシーの許可、管理者権限、entitlement のいずれも必要とせず、
  アプリ自身はネットワーク通信を行いません。

> macOS 向けリリースは **Developer ID で署名し、Apple の公証（notarize）を受けて**
> います（staple 済み）。Gatekeeper の警告なしに起動でき、オフラインでも動作します。

## 使い方

メニューバーの項目は、上段に上りの速度、下段に下りの速度を表示し、その横に直近 1 分の
グラフを描きます。中央線より上が上り、下が下りです。ダッシュは「この 1 秒には値が無い」こと、
項目全体が淡い表示は「選んだインターフェースが接続されていない」ことを表します。
代わりに別のインターフェースの数値を出すことはありません。

項目をクリックするとパネルが開きます。直近 3 分のグラフ、インターフェースのアドレスと
リンク速度、その 3 分間のピーク、起動後の累積転送量を表示します。リンク速度は
インターフェースの申告値であって、実際に運べる量の上限ではありません。設定も同じパネルにあります。

| 設定 | 選択肢 |
|---|---|
| Interface | Automatic — macOS がいま優先している物理回線（VPN 接続中でも同じ）— または任意のインターフェースを手動で指定 |
| Display | 数値とグラフ、数値のみ、グラフのみ。項目の幅はこの設定だけで決まり、他の要因では変わりません |
| Unit | バイト/秒（KB/s、MB/s）またはビット/秒（kbps、Mbps） |
| Colour | オフ: システムの項目と同じく、メニューバー自身の色で表示。オン: 上りと下りを色分け |
| Launch at login | 既定はオフ。macOS が「システム設定 › 一般 › ログイン項目」での承認を求めることがあります |

版数はパネルの最下部にあり、選択してコピーできます。

約 1 KB/s 未満の速度は 0 と 1 のあいだを行き来します。macOS は通常のアプリに対して、
バイトカウンタを 1 KiB 刻みで返すためです。

## ソースからのビルド

```bash
make build-app
```

`dist/NetMeter.app` が生成されます。署名にはキーチェーン内の Developer ID Application
を使います。無い場合もビルドは成功し、アプリは ad-hoc 署名のままになります。
ビルドした Mac で動かすにはそれで足ります。

```bash
make test
```

```bash
make run
```

`make run` はデバッグビルドを端末から起動します。先に、実行中の net-meter を終了して
ください。単一インスタンスガードが効くのは組み立て済みの `.app` だけです。デバッグ
バイナリには識別に使う bundle identifier が無いため、そのまま起動してメニューバーの
項目が 2 つになります。
